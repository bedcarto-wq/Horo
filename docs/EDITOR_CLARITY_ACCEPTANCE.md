# Приёмка Horo 0.4.1

## Реализовано

Контекст поведения/функции/ресурса, сигнатура, общие правки и отдельные экземпляры; единая доступность во всех путях; причины у недоступных действий и отказа провода; разрешённый неполный граф с индикатором; описания/подсказки реальных портов; группы свойств и одиночный сброс к дефолту через undo/redo; состояние запуска/ошибки; ограниченная консоль с уровнями, безопасной детализацией, копированием и переходами к источникам.

Только сеансовые фильтры/доступность, 1000 записей. Физический решатель, формат проектов, Task/Scope и игровые операции не изменены. Новых зависимостей нет. Подробности и точки изменения — [EDITOR_CLARITY.md](EDITOR_CLARITY.md).

## Среда и исходная проверка

Linux, Python 3.13.14, PySide6 6.8.3, pytest 8.4.2; `QT_QPA_PLATFORM=offscreen`.

База — **53c76e7d345502ebad3485f73bb5591b0b3dd834** из `version/0.4.0`; удалённая ветка и release target проверены до реализации. Сначала отсутствовала системная libGL, после установки Qt-библиотек исходный набор прошёл: **286 passed in 55.85 s**. Это проблема окружения, не скрытая исходная ошибка.

## Автоматически проверено локально

Первый полный прогон после интеграции: **317 passed in 135.79 s** (31 новая проверка). После дополнительных проверок реального контекстного меню и незавершённого ввода: **319 passed in 139.48 s**. Все прежние 286 тестов оставлены без изменения; итоговый прирост — 33 проверки. После двух заключительных небольших правок (устранение дублирующей диагностики и освобождение QMenu) повторно прошли соответствующие наборы: **73 passed in 32.05 s** и **2 passed in 0.81 s**. Полный набор точного опубликованного исходника дополнительно проверяет CI.

Команда:

```bash
QT_QPA_PLATFORM=offscreen python -m pytest -q --junitxml=test-results.xml
```

Новые проверки:

- Каталог/поиск/контроллер/drop/валидатор используют одну причину для поведения, функции и вложенной области, включая запрет второго входа функции при добавлении.
- Тип/контекст не путаются с неполными входами. Разрешённый неполный узел виден с ошибкой, сохраняется. Недопустимая связь не меняет документ; пояснение не требует открытия консоли.
- Происхождение открытия не следует за случайным выбором объекта; прямой ресурс не получает выдуманного владельца. У функции реальные имена/типы параметров/результатов.
- Все виды имеют описания; портовые подсказки содержат настоящие типы/обязательность/единицы и факт линии. Раскрытие описания не меняет сериализованный проект.
- Сброс массы/отскока/скорости/гравитации и компоненты преобразования берёт дефолт, не сохранённое значение, не меняет соседние компоненты; undo/redo работает.
- Проверен настоящий сигнал наведения на отключённую строку каталога и выбор сброса через QMenu клавишей Enter. Ожидающий ввод поля фиксируется до сброса, не перезаписывает дефолт поздним Qt-событием.
- Консоль фильтрует уровни, группирует одинаковые источники со счётчиком, не объединяет разные объекты/вызовы, ограничивает историю и очищает индекс. Copy не раскрывает received. Переход к удалённым источникам не падает.
- Сеансовые переключатели не переживают закрытие окна. Состояние отражает реальный запуск, обычную остановку, отказ валидации и ошибку выполнения. Авторское редактирование во время игры осталось изолированным.
- Диагностические метки вызовов различаются, ошибка очищает Runtime как прежде. Новый обычный проект корректно выполняется на двух объектах и повторно запускается с исходными координатами.
- Прежние тесты физики/динамики/проектов/планировщика также проходят в полном наборе.

## Визуальная проверка исходного Qt UI

Сгенерированы и осмотрены offscreen-снимки 1420×900 и 1024×768: контекст объекта/ресурса/функции, сигнатура, серые недоступные строки, маркировка неполной карточки, группы свойств, консоль и безопасные подробности. Заголовки групп переносятся, панели остаются встроенными. При маленьком окне и раскрытой большой консоли область графа уменьшается; можно изменить размеры/скрыть панель, вернуть компоновку и нажать «Показать всё». Это не обещание читаемости всего графа при любом масштабе.

Это осмотр изображений и автоматизированный GUI-тест, **не ручной Windows-плейтест**. Нельзя выдавать его за проверку EXE на чистом компьютере.

## Windows CI и архив

Workflow проверяет полный pytest на Ubuntu/Python 3.13 и Windows/Python 3.12. Затем Windows-job повторяет тесты, запускает PyInstaller, включает docs, 27 обычных проектов, лицензии и BUILD.txt. Публикация — `v0.4.1-preview`, ZIP **Horo-0.4.1-Windows-x64.zip**, только из push ветки `version/0.4.1`.

Этот документ коммитится **до запуска CI**. Конкретный результат CI, исходный SHA и проверка опубликованного ZIP сообщаются в итоговом сообщении; до завершения Actions наличие этого документа не доказывает успешную Windows-сборку. ZIP — сборка редактора, не экспорт игры.

## Ручная приёмка Windows EXE — ещё требуется

- [ ] Распаковать всю папку на Windows 10/11 x64 без Python, в путь с пробелами/кириллицей; запустить Horo.exe, сверить BUILD.txt.
- [ ] Открыть examples/27-editor-clarity: из объекта, напрямую ресурс, функцию и тело цикла; объяснить происхождение и общность ресурса.
- [ ] Найти недоступный узел, прочитать причину в строке/tooltip/пояснении при наведении. Проверить поиск и переключатель.
- [ ] Отклонить провод Число → Вектор2: увидеть причину над графом, не только в консоли. Создать разрешённый неполный узел, сохранить, исправить/отменить.
- [ ] Развернуть описание; прочитать типы/единицы и отметку линии. Изменить размер окна и компоновку, проверить удобство наведения на порт.
- [ ] ПКМ по свойству → дефолт; undo/redo. Убедиться, что соседнее поле и последний сохранённый документ не подменяют выбранное правило сброса.
- [ ] Запустить, остановить, намеренно вызвать ошибку; проверить постоянное состояние и отсутствие старых задач после перезапуска. Во время игры правки относятся к следующему снимку.
- [ ] Фильтры/счётчики/очистка консоли, раскрытие и копирование безопасных деталей без VS Code; переходы к графу/объекту/форме. Удалить источник и повторить переход.
- [ ] Перезапустить редактор: фильтры включены по умолчанию, недоступные скрыты. Открыть старый проект и проверить прежнее выполнение/физику.

## Ограничения

Нет новых операций языка, физики, экспорта, мини-карты, связей между ресурсами или пользовательских сохранений прогресса. Единицы произвольных чисел/векторов и пользовательской сигнатуры не выводятся из догадок. Типы тел, совместимость портов и физические ограничения остаются прежними. Консоль не является отладчиком со значениями переменных/полным дампом памяти; технический текст намеренно безопасный. Последний статус ошибки сохраняет причину остановки, но не заменяет runtime.running.
