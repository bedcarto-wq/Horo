# 0.4.1 — Контекст и диагностика

Откройте project.horo.json. Это обычный локальный проект, без специального поведения Runtime.

1. Выберите «Первый экземпляр», в свойствах откройте прикреплённый граф. Сверху виден именно этот объект. Выбор другого объекта сам по себе не меняет происхождение открытого графа.
2. Откройте тот же граф из ресурсов: теперь надпись «Ресурс графа», не выдуманный владелец. Редактирование общее, объектные переменные экземпляров раздельны.
3. Откройте «Получить смещение»: видны тип «Функция», параметры и результаты; они доступны на Вход функции и Вернуть результат и в панели сигнатуры.
4. В каталоге включите «Показать недоступные». В поведении «Вернуть результат» отключён с причиной; «Продолжить» доступен только в теле цикла. ПКМ на фоне открывает поиск с тем же правилом.
5. Попробуйте соединить выход числа с входом Смещение: отказ объяснён непосредственно над графом и продублирован в консоли. Красные треугольники — выполнение; синие кружки — данные. Отменённая связь не сохраняется.
6. Добавьте «Переместить объект» без входов: карточка помечена ⚠, но узел разрешён и неполный граф можно сохранить. Запуск требует исправления; удалите тестовый узел или отмените создание.
7. Разверните «Описание» карточки, наведите на порты: типы, обязательность, единицы. Для подключённых входов видна пометка «← линия».
8. В свойствах объекта измените X. ПКМ по полю → «Вернуть значение по умолчанию: 0». Это не последнее сохранённое X; Y не меняется. Проверьте отмену/повтор.
9. Запустите исправный исходный проект: Space перемещает оба объекта на (45,15) через общий граф-функцию и цикл. Статус — «Игра запущена». Редактирование по-прежнему применяется только при следующем запуске. Stop возвращает «Редактирование».
10. При ошибке проверьте фильтры консоли, раскрытие безопасных технических сведений и копирование. Есть отдельные переходы к графу/объекту/форме, если источник имеется. Удалите источник после сообщения — переход объяснит отсутствие, не упадёт.

Фильтры и показ недоступных сохраняются только до закрытия редактора. История консоли ограничена 1000 записями, в проект не записывается. Это сборка редактора, не экспорт игры.
